# 🌲 Forest Adventure: A Choice-Based Interactive Survival Game

## 📖 Introduction

Forest Adventure is a web-based interactive survival game developed using React.js.  
The game places players inside a mysterious forest where every decision affects the story progression and final outcome.

The project is based on **choice-driven gameplay**, allowing users to experience multiple story paths, endings, and survival outcomes.

This project demonstrates how modern frontend technologies can be used to build immersive, story-based web applications.

---

# 🎯 Project Objectives

The main objectives of this project are:

- Build an interactive story-based game using React.js
- Implement dynamic scene navigation without page reloads
- Save and restore game progress using Local Storage
- Integrate background music and sound effects
- Generate downloadable survival reports
- Apply modern UI/UX concepts such as glassmorphism and overlays

---

# 🛠 Technologies Used

| Technology | Purpose |
|------------|----------|
| React.js | Frontend framework |
| JavaScript (ES6) | Game logic and state management |
| JSON | Story and scene storage |
| CSS3 | Styling and animations |
| HTML5 Audio API | Music and sound effects |
| Local Storage | Save game progress |
